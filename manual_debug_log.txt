**Introduction**

**Conditional Statements**
-------------------------

Conditional statements are used to execute different blocks of code based on certain conditions. In Python, we use the `if` statement to check conditions.

### If Statement

The `if` statement is used to check if a condition is true. If the condition is true, the code inside the `if` block is executed.

```python
if condition:
    # code to be executed if condition is true
```

For example, let's say we want to check if Thomas is old enough for kindergarten. We can use the following code:

```python
if Thomas_age < age_at_kindergarten:
    print("Thomas should be in preschool.")
```

In this example, we are checking if Thomas's age is less than the age at kindergarten. If the condition is true, we print "Thomas should be in preschool."

### Else Statement

The `else` statement is used to specify a block of code to be executed if the condition in the `if` statement is false.

```python
if condition:
    # code to be executed if condition is true
else:
    # code to be executed if condition is false
```

For example, let's say we want to check if Thomas is old enough for kindergarten. We can use the following code:

```python
if Thomas_age < age_at_kindergarten:
    print("Thomas should be in preschool.")
else:
    print("Thomas should be in kindergarten or another class.")
```

In this example, we are checking if Thomas's age is less than the age at kindergarten. If the condition is true, we print "Thomas should be in preschool." If the condition is false, we print "Thomas should be in kindergarten or another class."

### Elif Statement

The `elif` statement is used to check another condition if the first condition is false.

```python
if condition1:
    # code to be executed if condition1 is true
elif condition2:
    # code to be executed if condition1 is false and condition2 is true
```

For example, let's say we want to check if Thomas is old enough for kindergarten. We can use the following code:

```python
if Thomas_age < age_at_kindergarten:
    print("Thomas should be in preschool.")
elif Thomas_age == age_at_kindergarten:
    print("Thomas should be in kindergarten.")
else:
    print("Thomas should be in another class.")
```

In this example, we are checking if Thomas's age is less than the age at kindergarten. If the condition is true, we print "Thomas should be in preschool." If the condition is false, we check if Thomas's age is equal to the age at kindergarten. If the condition is true, we print "Thomas should be in kindergarten." If the condition is false, we print "Thomas should be in another class."

**Error Handling**
------------------

Error handling is essential for writing robust and reliable code. There are three types of errors that we can encounter in Python:

### Syntax Errors

Syntax errors occur when we write code that is not syntactically correct. For example, if we forget to include quotes around a string, we will get a syntax error.

```python
print hello world  # syntax error
```

To troubleshoot syntax errors, we can look at the error message, which will indicate the line and column where the error occurred.

### Runtime Errors

Runtime errors occur when we write code that is syntactically correct but causes an error at runtime. For example, if we try to divide by zero, we will get a runtime error.

```python
10 / 0  # runtime error
```

To troubleshoot runtime errors, we can look at the error message, which will indicate the type of error and the line where it occurred.

### Semantic Errors

Semantic errors occur when we write code that is syntactically correct but does not produce the expected result. For example, if we assign a value to a variable but forget to use it, we will get a semantic error.

```python
name = "Kevin"
print hello name  # semantic error
```

To troubleshoot semantic errors, we need to carefully review our code and make sure that we are using all the variables and functions that we have defined.

## Types of Errors in Programming
- **Syntax Errors**: These are errors that occur when the code is not written in a way that is understandable by the programming language. This can include missing or mismatched brackets, missing or extra semicolons, and other similar issues.
- **Runtime Errors**: These are errors that occur when the code is executed and the program encounters an issue that prevents it from running correctly. This can include errors such as division by zero, attempting to access an index that does not exist in a list, and other similar issues.
- **Semantic Errors**: These are errors that occur when the code is written correctly in terms of syntax and is executed without any runtime errors, but the output or behavior of the program is not what was expected. This can include errors such as variables not being assigned the correct value, functions not being called correctly, and other similar issues.

## Understanding Semantic Errors
- **Definition**: Semantic errors are errors that occur when the code is written correctly in terms of syntax and is executed without any runtime errors, but the output or behavior of the program is not what was expected.
- **Characteristics**: Semantic errors are notoriously hard to troubleshoot because everything is working as it should based on how the code is programmed, but the expected result is not being achieved.
